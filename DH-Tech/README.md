# D.H Tech ⚡

Proyecto académico de HTML, CSS y JavaScript para la práctica de reconstrucción de una presencia digital.

## Sobre el proyecto
D.H Tech es una empresa ficticia dominicana de reparación electrónica que regresa a Internet después de una desaparición misteriosa.

## Archivos
- `index.html`: página de inicio con pantalla de error recuperable.
- `historia.html`: historia del misterio.
- `servicios.html`: catálogo de servicios reinventados.
- `contacto.html`: formulario de demostración y pruebas ficticias del incidente.
- `css/estilos.css`: diseño, animaciones y estilos responsive.
- `js/script.js`: pantalla de recuperación, menú móvil, tema claro/oscuro, easter egg y chatbot.

## Funciones incluidas
1. Pantalla de error inicial que se recupera al hacer clic.
2. Easter egg: escribe `FENIX` con el teclado para mostrar un mensaje secreto.
3. Chatbot local basado en palabras clave.
4. Modo claro/oscuro.
5. Diseño adaptable a computadoras, tabletas y teléfonos.
6. Formulario de demostración que no envía datos a un servidor.

## Cómo abrirlo
Abre `index.html` en un navegador. Para una experiencia de desarrollo más cómoda, puedes usar la extensión Live Server de Visual Studio Code.

## Publicar con GitHub Pages
1. Sube todos los archivos al repositorio.
2. En GitHub, entra en **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona `main` y la carpeta `/ (root)`, y guarda.
5. Espera a que GitHub publique el sitio y visita la URL que aparezca en esa sección.

## Invitar al colaborador
1. Abre el repositorio en GitHub.
2. Ve a **Settings → Collaborators** (el nombre puede variar ligeramente).
3. Selecciona **Add people**.
